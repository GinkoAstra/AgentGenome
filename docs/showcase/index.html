WHY AGENTGENOME

Turn open-ended chats into explicit, composable work.

Give each Agent a concrete definition and each Node a bounded contract, so structure replaces an ever-growing conversation.

01 / AGENT DEFINITION

More than a Skill: define the Agent

Inspired by Docker’s explicit runtime boundary and Kubernetes’ declarative objects, Graph YAML defines the Agent, Task, tools, inputs, and acceptance boundary. Multi-turn execution becomes an SOP whose Nodes can be split, reused, and composed.

declared Agent · composable SOP
02 / TASK-SCOPED CONTEXT

Shrink the context, keep the structure

Give every Worker its own Task contract, declared inputs, and tools—not the entire conversation. Dependencies, reviews, and artifacts carry continuity as structured state, reducing reliance on long transcripts or Markdown memory files.

task-scoped context · structured continuity
03 / COST CONTROL

Design cost into the SOP

Explicit inputs, outputs, and acceptance rules make each step’s work easier to scope and compare. Bound provider calls, tool calls, rounds, depth, and runtime; use per-step evidence to guide model and token allocation by task complexity.

declared budgets · measurable steps

START LOCALLY

Bring your own model.
Keep your workflow inspectable.

Build the native Rust Core, install the ordinary Pi integration, and explicitly start the service. Then enable /agentgenome in a new Pi session.

Rust toolchainPi CLIConfigured model
Open the full quickstart ↗
terminal
# from the AgentGenome repository
cargo build --release --locked --manifest-path rust/Cargo.toml
CORE="$PWD/rust/target/release/agentgenome"
"$CORE" client install --client pi

# start the service with your provider and model
"$CORE" start --backend pi \
  --provider YOUR_PROVIDER --model YOUR_MODEL

# then open a new Pi session and enter:
/agentgenome
What it proves

Versioned execution and explicit acceptance

Real examples separate Worker output, Checker receipts, runtime state, and independent artifact verification.

What it doesn’t claim

“The model said so” is not enough

No arbitrary side-effect replay, open-ended research correctness, or universal CLI subagent support is implied.
